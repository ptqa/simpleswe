# Repository Instructions

## Product Decisions

`PRODUCT.md` is authoritative. Do not modify it unless the user explicitly asks to change `PRODUCT.md`.

## Linters

Do not disable or weaken linters to make checks pass. This includes removing enabled linters, adding exclusions or `nolint` suppressions, lowering severity, or relaxing linter settings.

Fix the code that violates the lint rule. If a rule cannot be satisfied without changing intended behavior, ask the user before changing any lint configuration.
